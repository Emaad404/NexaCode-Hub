Challenge: Find Peak Element

Write a function findPeak(arr) that takes an array of numbers and returns the index of a "peak" element. An element is a peak if it is greater than or equal to its neighbors.

For elements on the edges, they only need to be greater than or equal to their single neighbor.

Example 1: 
findPeak([1, 2, 3, 1]) => 2 // Value 3 is peak
Example 2: 
findPeak([1, 2, 1, 3, 5, 6, 4]) => 5 // Value 6 is peak

HISTORY

The Story of NexaCode

How we went from writing scripts on personal laptops to forming hundreds of engineers worldwide.

01

The Struggle

When starting out, we spent months watching video tutorials. We memorized syntax commands, but we couldn't build a single application from scratch. The tutorial hell was real, and it was draining.

02

The Learning Journey

Real breakthroughs occurred when we got jobs inside companies. Junior developers learned through pull request reviews. The line-by-line feedback from team leads accelerated our growth 10x faster than any class.

03

The Missing Gap

Most code academies teach syntax rules, then dump students in the job market with copy-pasted portfolio templates. There was a massive gap between academic coding and production-level system design.

04

The Vision

We wanted to package the big tech engineering workspace structure into an elite programming academy. A space where students are treated like professional software engineers from day one.

05

The Creation of NexaCode

We launched our first cohort in 2023. Today, NexaCode graduates work at Vercel, Linear, Apple, Stripe, and build core tech stacks at top-tier VC-backed startups.
